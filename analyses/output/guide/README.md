# Desk Field Guide

Page: https://claude.ai/artifact/T4gimQad24JCNFSKsCTbwM (private to Rk), linked from the HQ nav.

Plain-language guide to every desk page, scheduled run, tracker and rule, with real graded calls
from the Desk Ledger. Static page: numbers are as read on 26 Nov 2026.

Build: edit `guide_body.html` (content), `guide.css` (layout on top of `analyses/design/desk_theme.css`)
or `guide.js` (the call-flow drawing and range bars), then run `python analyses/output/guide/build.py`
and republish `desk_guide.html` to the same URL. Update the "What's changing" section when the
five upgrades in progress (failure alarm, FRED grading, one set of calls per day, archived analysts,
single Today page) merge.
